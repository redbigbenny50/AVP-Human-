ALSO CHECK, not automatable
---------------------------
1. If blib-gradle is a git submodule, remove it properly:
       git submodule deinit -f blib-gradle
       git rm -f blib-gradle
       rm -rf .git/modules/blib-gradle

2. eclipse-formatter.xml must exist at the repo root - multiloader-common's spotless block
   references "$rootDir/eclipse-formatter.xml". AVP-Alien has one; copy it across if avp_human
   does not (the blib plugin supplied its own formatter config).

3. CHANGELOG.md must exist at the repo root - both publishMods blocks read it.

4. key.properties at the root gates publishing. Without it the publishMods blocks are skipped
   entirely, so a normal build is unaffected.

5. The Discord webhook from the old blib { mod { publish { discordWebhook { } } } } block has
   NO equivalent in me.modmuss50.mod-publish-plugin and is NOT reproduced. If the MU/TH/UR
   announcement matters it needs a separate CI step.
